## 📖 Sobre o Projeto
 
O **FitFlow** é uma aplicação web para gerenciamento de treinos físicos. A ideia é simples: criar, executar e acompanhar seus treinos de forma intuitiva, com histórico completo e métricas de evolução.
 
> 🎯 **Objetivo principal:** Aprender na prática com um projeto real, usando Spring Boot no back-end e Angular no front-end.
 
---
 
## ✨ Funcionalidades
 
### MVP (Versão 1.0)
- [ ] Cadastro e login de usuários (JWT)
- [ ] Catálogo de exercícios pré-cadastrados
- [ ] Criação de treinos A/B/C por grupo muscular
- [ ] Montagem de "playlist" de treino com exercícios
- [ ] Registro de séries, repetições, peso e tempo de descanso
- [ ] Anotações livres por exercício
- [ ] Execução de treino com check por exercício
- [ ] Conclusão e salvamento do treino realizado
### Versão 2.0
- [ ] Histórico de treinos (retenção de 1 mês)
- [ ] Dashboard de métricas completo
- [ ] Exportação de relatório de evolução (PDF)
- [ ] Compactação automática: após 1 mês, dados viram métricas
